本项目包含 **三大部分**，从应用层系统编程到内核驱动再到操作系统原理，构建完整的底层技术栈：

```

└─────────────────┴─────────────────┴─────────────────┘
```

## 第一部分：Linux 系统编程

> 从零学习 Linux C 语言系统编程，覆盖从文件操作到多线程的全部核心 API。

| 章节 | 内容 | 关键技能 |
|------|------|----------|
| 环境搭建 | VMware + Ubuntu | 开发环境配置 |
| Linux 基本命令 | ls、cd、cp、chmod、tar、df | Shell 操作 |
| GCC 编译与库 | 编译四步骤、静态库 `.a`、动态库 `.so`、Makefile | 构建工具链 |
| 文件 I/O | 系统 IO vs 标准 IO、缓冲区机制 | `open/read/write/lseek` vs `fopen/fwrite/fread` |
| 进程管理 | fork、exec、waitpid、孤儿/僵尸进程 | 保活进程实战 |
| 进程间通信 (IPC) | 匿名管道、FIFO、共享内存、消息队列、信号、信号量 | 6 种 IPC 对比与选型 |
| 多线程编程 | pthread、互斥锁、条件变量 | 生产者-消费者模型 |

## 第二部分：Linux 驱动开发

> 基于正点原子 i.MX6ULL 开发板，按**五条递进主线**组织，聚焦"为什么变、变在哪里"。

| 阶段 | 实验 | 主线 | 核心变化 |
|------|------|------|----------|
| 一 | 1~3 | **字符设备框架演进** | 虚拟驱动 → 真实 GPIO → 新框架（动态设备号） |
| 二 | 4~6 | **硬件描述层演进** | 硬编码地址 → 设备树 → GPIO 子系统（零寄存器代码） |
| 三 | 7 | **框架巩固** | 蜂鸣器验证复用性（与 LED 驱动 99% 代码相同） |
| 四 | 8~11 | **并发保护演进** | 原子操作 → 自旋锁 → 信号量 → 互斥体（含决策树） |
| 五 | 12~13 | **IO 模型演变** | 忙等轮询 → 内核定时器回调 → 中断（待学） |

> 📌 每个实验只改 ~10% 代码，看懂变化就懂了驱动架构设计。

## 第三部分：MIT 6.S081 (xv6) 操作系统

> 基于 MIT 操作系统课程，理解内核的进程管理、虚拟内存和系统调用实现。

| 章节 | 内容 | Lab 实战 |
|------|------|----------|
| 进程和内存 | 宏内核、用户态/内核态、系统调用 fork/exec/wait | Lab 1: sleep、pingpong、primes、find、xargs |
| 操作系统核心 | CPU 权限模式、ecall 指令、单体内核 vs 微内核 | Lab 2: trace（系统调用追踪）、sysinfo |
| 虚拟内存 | 页表三级映射、TLB、内核页表、隔离性 | Lab 3: 打印页表、专属内核页表、simplify copyin |
