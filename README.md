# Linux 系统编程 & xv6 操作系统学习笔记

> 📅 2026年2月 - 6月 | 🎯 为嵌入式/底层开发打基础

## 项目简介

本项目是个人学习笔记，涵盖两大模块：

### 第一部分：Linux 系统编程

从零开始学习 Linux 环境下的 C 语言系统编程，涵盖以下内容：

| 章节 | 内容 |
|------|------|
| 环境搭建 | VMware + Ubuntu 安装配置 |
| Linux 基本命令 | ls、cd、cp、rm、chmod、tar、df 等 |
| GCC 编译与库 | 编译四步骤、静态库 `.a`、动态库 `.so`、Makefile、CMake |
| 文件 I/O | 系统 I/O（open/read/write/lseek）vs 标准 C I/O（fopen/fwrite/fread）|
| 进程管理 | fork、exec、wait/waitpid、孤儿/僵尸进程、保活进程实战 |
| 进程间通信（IPC）| 匿名管道、命名管道(FIFO)、共享内存、消息队列、信号、信号量 |
| 多线程编程 | pthread 创建/退出/等待、互斥锁、条件变量 |

### 第二部分：MIT 6.S081 (xv6) 操作系统

基于 MIT 6.S081 课程，学习操作系统内核设计与实现：

| 章节 | 内容 |
|------|------|
| 进程和内存 | 宏内核、用户态/内核态、系统调用、文件重定向 |
| Lab 1: Unix Utilities | rm、sleep、pingpong（管道通信）、primes（并发素数筛）、find、xargs |
| 操作系统核心概念 | CPU 权限模式、ecall 指令、内核架构、进程双栈机制 |
| Lab 2: 系统调用 | trace（系统调用追踪）、sysinfo（系统状态收集）|
| 虚拟内存 | 页表三级映射、TLB 缓存、内核页表、隔离性原理 |
| Lab 3: 页表 | 打印页表、进程专属内核页表、simplify copyin/copyinstr |
